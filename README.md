# סורק PUT / CALL

אפליקציית Streamlit עצמאית לאייפון. עוברת על חוזי PUT ו-CALL לפי הכללים שלך, עם מציאת מניות לפי מדד (S&P 500 / Nasdaq 100).
אין ציון ואין דירוג. ההחלטה שלך.

- PUT = מכירה מכוסה במזומן (התחייבות = סטרייק x 100). כלל החשיפה חל על PUT בלבד.
- CALL = מכירה מכוסה במניות שכבר יש לך (התחייבות = שווי 100 מניות במחיר הנוכחי). לא CALL חשוף.
- אותם כללים חלים על שני הסוגים (Delta, תשואה, מרווח, OI, xEM, דוחות).

## קבצים

| קובץ | תפקיד |
|---|---|
| `app.py` | המסך |
| `styles.py` | העיצוב (CSS) וטבלאות HTML קריאות |
| `rules.py` | הכללים ובדיקת כל כלל בנפרד |
| `screener.py` | סריקת שרשרת PUT/CALL ופריסת העמודות של הגיליון |
| `data_yf.py` | שליפה מ-yfinance, מטמון, רישום שגיאות אמיתיות, בדיקת חיבור |
| `universe.py` | רשימות מדדים וסינון לפי מחיר (העתק של `universe_screener.py`) |
| `options_engine.py` | מנוע Black-Scholes (העתק, ללא שינוי) |
| `tests/` | 25 בדיקות, ללא רשת |

## הרצה מקומית

```
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m streamlit run app.py --server.address 0.0.0.0
```

באייפון (על אותה רשת Wi-Fi): `http://<כתובת-ה-IP-של-המחשב>:8501`, ואז שיתוף > הוסף למסך הבית.

## פריסה ל-Streamlit Community Cloud

1. ריפו חדש ב-GitHub (למשל `put-call-screener`), פרטי.
2. העלי את כל הקבצים כאן (בלי `.venv`).
3. ב-share.streamlit.io: New app, בחרי את הריפו, Main file path = `app.py`.
4. פתחי את האפליקציה באייפון והוסיפי למסך הבית.

## אם אין נתוני אופציות בענן

באפליקציה הקיימת נתוני האופציות לא נטענים בסטרימליט קלאוד. כאן יש חלונית **"בדיקת חיבור לנתונים"** בראש המסך:
לחצי "הרץ בדיקה על SPY" וקראי איזה שלב נכשל (מחיר, פקיעות או שרשרת) ומה השגיאה המדויקת.
זו הנקודה הראשונה לבדיקה לפני שמשנים כל דבר אחר.
